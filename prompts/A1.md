# Arm A1 — spec + listing, no source, no registry

Write one Storybook story file. This is a controlled measurement, so the constraints matter
more than usual.

Working directory: `{DIR}`

Stay inside it. Do not read, list, or glob anything outside that directory — not a parent,
not a sibling. There is material there that would invalidate the measurement.

## Your inputs

- `SPEC-SCREEN.md` — the screen to build
- `LISTING.txt` — every component file in the host, with its export names

That is all you get. The host is a React + TypeScript product built on **{LIB}**. You do
not have the component source. Write the screen from the spec, the listing, and what you
know about React and {LIB}.

## Your output

`TimelineScreen.stories.tsx`, in your working directory.

- CSF3: `import type { Meta, StoryObj } from "@storybook/react";`, a default-exported
  `Meta`, and one named story.
- Import every host component through the `~/` path alias exactly as the listing spells the
  file, e.g. `src/components/post-card.tsx` is imported as `~/components/post-card`. Never
  use a relative import.
- Named exports. The listing tells you the export names.
- Use only the host's own components from `src/components/`. Do not import from any library
  directly.

## Rules

- Do NOT run `tsc`, `npx tsc`, or any typechecker. There is no `node_modules` and this is
  deliberate. Your first complete version is what gets scored.
- Do NOT create any file other than `TimelineScreen.stories.tsx`.
- Where you are unsure of a prop name or a prop's type, make your best judgment and move
  on. Guessing is the thing being measured — do not hedge by leaving a component out.
- Build the whole tree the spec describes. Every component in it, all four posts.

## Final report

Return exactly this, concise and factual:

1. Whether you completed the full tree in the spec, and anything you left out
2. The props you were least confident about, and what you guessed
3. Counts: files opened, greps/searches run, shell commands run
4. Nothing else — no summary of the file's contents
